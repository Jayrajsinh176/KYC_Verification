VerifyHub B2B KYC Platform — Completed API Report

Complete REST API Reference for Frontend Developers · Authentication, KYC Verification Engine, Wallet & Admin Suite

Base Headers Required for All Requests: Accept: application/json  |  Content-Type: application/json

Protected Endpoints (Sanctum Auth): Pass Bearer token in header: Authorization: Bearer <token>

Standard Success Response Envelope: {"success": true, "message": "...", "data": {...}}

1. Authentication & Session APIs

1. Super Admin Login
POST /api/auth/admin/login
Where used in Frontend: Admin Portal Login Screen (/admin/login)
Why used: Authenticates platform administrator, verifies admin privileges, logs security audit trail, and returns Sanctum Bearer access token.
Request format:

  "password": "password123"
}
Response format:

⚡ Frontend Setup Quick-Start (Axios / Fetch)

Setting Value Note
Base URL http://127.0.0.1:8000/api Configure in frontend .env as VITE_API_URL
Default Headers Accept: application/json
Content-Type: application/json		 Ensures Laravel returns JSON responses on errors instead of HTML
Auth Header Authorization: Bearer <token> Add to Axios request interceptor using stored token
Sample Axios Client Setup:
import axios from 'axios';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_URL || 'http://127.0.0.1:8000/api',
  headers: {
    'Accept': 'application/json',
    'Content-Type': 'application/json',
  },
});

api.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

export default api;
